# DSH Apps — 入口应用层

> 版本: 0.1.1-rc.2
> 仓库: https://github.com/deepseek-ai/deepseek-harness
> 许可证: MIT

## 项目概述

`apps/` 是 DeepSeek Harness (DSH) 的**入口应用层**，包含两个独立应用：

| 应用 | 包名 | 说明 |
| :-- | :-- | :-- |
| `apps/cli` | `@deepseek-ai/dsh` | CLI 入口：Profile 启动、插件管理、Web UI 别名 |
| `apps/web` | `@deepseek-ai/dsh-web-frontend` | Web 前端：Vite 构建的 React SPA |

## 核心职责

```
apps/
├── cli/              ← 用户命令行入口 (dsh web / dsh plugin / dsh --dump-config)
│   ├── src/bin.ts    ← CLI 入口，按 mode 分发动态 import
│   ├── src/args.ts   ← 命令行参数解析 (commander)
│   ├── src/profile-boot.ts ← Profile 启动逻辑
│   └── config/       ← 内置 Agent Preset (standard/cordis/code/minimal)
│
└── web/              ← Web 前端入口
    ├── src/main.ts   ← 挂载 #root，委托给 dsh-client-web
    ├── dist/         ← 构建产物（被 cli 的 dsh web 静态托管）
    └── tests/        ← E2E 快照测试 (Playwright)
```

## 技术栈

| 层 | 技术 |
| :-- | :-- |
| CLI 框架 | commander.js |
| 前端框架 | React 18 + TypeScript 6 |
| 构建工具 | Vite 6 + tsdown |
| 测试 | Vitest 4 + Playwright |
| 模块系统 | ESM (`"type": "module"`) |
| 包管理 | pnpm 11.7.0 (workspace 协议) |

## 项目结构

```
DeepSeekHarness/
├── apps/
│   ├── cli/              ← @deepseek-ai/dsh
│   │   ├── src/
│   │   │   ├── bin.ts          ← CLI 入口
│   │   │   ├── args.ts         ← 参数解析
│   │   │   ├── profile-boot.ts ← Profile 启动
│   │   │   ├── plugin.ts       ← 插件管理
│   │   │   └── dump-config.ts  ← 配置导出
│   │   ├── config/
│   │   │   └── agent-presets/  ← 内置 preset
│   │   │       ├── standard/   ← 标准模式
│   │   │       ├── cordis/     ← 创造模式
│   │   │       ├── code/       ← PTC 模式
│   │   │       ├── minimal/    ← 极简模式
│   │   │       └── my-agent/   ← 用户自定义
│   │   ├── tests/
│   │   └── package.json
│   │
│   └── web/              ← @deepseek-ai/dsh-web-frontend
│       ├── src/main.ts
│       ├── dist/              ← 构建产物
│       ├── tests/             ← E2E 测试
│       └── package.json
│
├── packages/             ← 核心包（~130 个插件）
├── vendor/               ← 第三方 vendor（cordis, cosmokit 等）
├── scripts/              ← 构建/发布脚本
└── package.json          ← monorepo 根
```

## 关键依赖关系

```
apps/cli ──depends──> packages/bundle/base (dsh-base)
                  ├──> packages/bundle/web-app (dsh-web-app)
                  ├──> packages/core/* (agent, session, tools)
                  ├──> packages/shell/* (bash, pwsh)
                  ├──> packages/fs/* (文件系统)
                  └──> packages/llm/* (模型适配)

apps/web ──depends──> packages/client/* (UI 组件)
                  └──> packages/client/web (shell 库)
```
