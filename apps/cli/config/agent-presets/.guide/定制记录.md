## 快速切换

### 隐藏 / 显示 preset

**隐藏**（重命名加 `_` 前缀）：

```powershell
cd "E:\baizhoucode\companyagent\dsharness\apps\cli\config\agent-presets"
Rename-Item "standard" "_standard"
Rename-Item "code" "_code"
Rename-Item "cordis" "_cordis"
Rename-Item "minimal" "_minimal"
```

**恢复**（去掉 `_` 前缀）：

```powershell
cd "E:\baizhoucode\companyagent\dsharness\apps\cli\config\agent-presets"
Rename-Item "_standard" "standard"
Rename-Item "_code" "code"
Rename-Item "_cordis" "cordis"
Rename-Item "_minimal" "minimal"
```

### 切换排序

修改 `preset.yml` 中的 `order` 值：

| order | 含义 |
| :-- | :-- |
| 1 | 最优先显示 |
| 2+ | 按数值排序 |

---

## 完整恢复为原始状态

```powershell
cd "E:\baizhoucode\companyagent\dsharness\apps\cli\config\agent-presets"

# 1. 恢复隐藏的 preset
Rename-Item "_standard" "standard"
Rename-Item "_code" "code"
Rename-Item "_cordis" "cordis"
Rename-Item "_minimal" "minimal"

# 2. 删除百洲定制（可选）
Remove-Item "bzcode" -Recurse

# 3. 重启 DSH
.\start-dsh.ps1 restart
```
