# 包依赖关系

## 依赖层次

```
Layer 0 (无依赖):  util/*, brand
Layer 1 (基础):    scope, session, llm, attachment
Layer 2 (核心):    agent, tools, system-prompt
Layer 3 (能力):    fs, shell, sandbox, web, lsp, mcp, sdk
Layer 4 (策略):    fs-local, bash-local, pwsh-local, sandbox-local, ...
Layer 5 (面向模型): tool-fs, tool-bash, tool-pwsh, tool-web, tool-lsp, ...
Layer 6 (聚合):    bundle/*, client/*
```

## 16 个能力接缝（Seam）

每个接缝 = Service Definition + Provider + Consumer

| 接缝 | Definition | Provider | Consumer |
|:--|:--|:--|:--|
| Shell | `dsh-shell` | bash-local, bash-sandbox, pwsh-local, pwsh-sandbox | tool-bash, tool-pwsh |
| FS | `dsh-fs` | fs-local, fs-sandbox, fs-e2b | tool-fs, tool-fs-search |
| Subprocess | `dsh-subprocess` | local | — |
| Terminal | `dsh-terminal` | local | tool-terminal |
| Sandbox | `dsh-sandbox` | sandbox-local (bwrap/landlock/Seatbelt) | — |
| LLM | `dsh-llm` | llm-deepseek, llm-pi-ai, llm-retry | — |
| Web | `dsh-web` | web-fetch-http, web-search-deepseek | tool-web |
| LSP | `dsh-lsp` | lsp-stdio | tool-lsp |
| SubAgent | `dsh-subagent` | spawn, fork, ACP, Codex, Claude Code | — |
| Session Persistence | `dsh-session-persistence` | jsonl, sqlite | — |
| Storage | `dsh-storage` | json, sqlite, domain | — |
| Credentials | `dsh-credentials` | credentials-local | — |
| Settings | `dsh-settings` | settings-file | — |
| Compaction | `dsh-compaction` | compaction-basic, tool-result-pruner | — |
| Spill | `dsh-spill` | spill-local | — |
| Skill | `dsh-skill` | skill-filesystem | tool-skill |

## 核心依赖链

```
cordis (vendor)
  └─ dsh-brand (类型原语)
       └─ dsh-scope (作用域)
            └─ dsh-session (会话日志)
                 ├─ dsh-llm (LLM 适配器)
                 │    └─ dsh-agent (Agent 注册表)
                 │         └─ dsh-agent-loop (Agent 循环)
                 │              ├─ dsh-tools (工具注册表)
                 │              │    ├─ dsh-tool-fs
                 │              │    ├─ dsh-tool-bash
                 │              │    └─ dsh-tool-web
                 │              └─ dsh-system-prompt (Prompt 装配)
                 └─ dsh-fs / dsh-shell / dsh-sandbox (能力接缝)
```

## Bundle 聚合依赖

### dsh-base（核心 bundle，70+ deps）

聚合所有核心包：core/*, llm/*, fs/*, shell/*, sandbox/*, session/*, web/*, lsp/*, credentials/*, settings/*, storage/*, compaction/*, spill/*, goal/*, jobs/*, skill/*, typert/*, context/*, code-runtime/*, interaction/*, attachment/*, hooks/*, guard/*, plan/*, preset/*, subagent/*, workspace/*, todo/*

### dsh-web-app（浏览器 bundle，100+ deps）

在 dsh-base 基础上添加：client/*, host/*, api/*, mcp/*, sdk/*, extensions/*

### dsh-headless（无服务器 bundle）

精简 bundle，仅包含：core/*, llm/*, session/*, shell/*, sandbox/*, fs/*（无 Host/HTTP/UI）

## Host vs Client 分配

| 聚合 | 包 | 说明 |
|:--|:--|:--|
| **Host** (`tsconfig.host.json`) | core/*, llm/*, fs/*, shell/*, sandbox/*, session/*, web/*, lsp/*, credentials/*, settings/*, storage/*, compaction/*, spill/*, goal/*, jobs/*, skill/*, typert/*, context/*, code-runtime/*, interaction/*, attachment/*, hooks/*, guard/*, plan/*, preset/*, subagent/*, workspace/*, host/*, api/*, acp/*, e2b/*, bundle/*, boot/* | 服务端 |
| **Client** (`tsconfig.client.json`) | client/*, extensions/* (部分), mcp/*, sdk/*, bundle/* (部分) | 浏览器端 |

**约束**：新包只能注册到其中一个聚合。唯一例外：`api/remotes` 拆分生成的 contracts。
