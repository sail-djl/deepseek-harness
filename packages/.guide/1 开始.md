# packages/ — 核心包目录

## 概述

`packages/` 是 DeepSeek Harness (dsh) 的核心代码目录，包含 **50+ 个 TypeScript 包**，每个包对应一个独立的能力域。所有包通过 pnpm workspaces 统一管理，npm scope 为 `@deepseek-ai/dsh-*`。

## 核心理念

- **一切皆插件**：每个能力由 Cordis 插件提供，可随时替换
- **能力接缝（Seam）**：每个能力域遵循 Service Definition → Provider → Consumer 三层模式
- **双聚合架构**：Host（服务端）和 Client（客户端）独立构建，新包只能注册到其中一个

## 两种导出模式

| 模式              | 导出方式                                                 | 用途                          | 示例                                   |
| :---------------- | :------------------------------------------------------- | :---------------------------- | :------------------------------------- |
| **Service** | `default export` extends `Service`                   | 核心接缝包，注册为`ctx.xxx` | `dsh-fs`, `dsh-shell`, `dsh-llm` |
| **Plugin**  | named exports (`name`/`inject`/`Config`/`apply`) | 工具包、实现包、策略包        | `dsh-bash-local`, `dsh-tool-fs`    |

**注意**：混合两种模式会导致 Loader 丢弃 Function Plugin 的命名空间。

## 开发约定

详见 `AGENTS.md`，核心要点：

- 新包只能注册到 Host 或 Client 其中一个聚合
- `src/types.ts` 只放类型，不含运行时代码
- 测试文件放在包级 `tests/` 目录（非 `src/__tests__/`）
- 每个包必须有 `./invariant` 注册 manifest name
- README 和 JSDoc 是变更的一部分，需同 commit 更新
