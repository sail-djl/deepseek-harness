# 构建与测试

## TypeScript 双聚合架构

```
tsconfig.json              ← 解决方案根
├── tsconfig.host.json     ← Host 聚合（服务端）
├── tsconfig.client.json   ← Client 聚合（客户端）
├── tsconfig.base.json     ← 共享编译选项 + paths 映射
└── tsconfig.base.client.json ← 浏览器编译设置（JSX, DOM）
```

**约束**：
- `tsconfig.base.json` 永远不加 `include` 或 `files`
- 新包只能注册到 Host 或 Client 其中一个
- `api/remotes` 是唯一 split 的包

## 每个包的 tsconfig 标准

```json
{
  "extends": "tsconfig.base.json",      // Client 包用 tsconfig.base.client.json
  "compilerOptions": {
    "rootDir": "src",
    "outDir": "lib/types"
  },
  "references": [
    { "path": "依赖包路径" },
    { "path": "../runtime-diagnostics/invariants" }
  ]
}
```

## 构建命令

```bash
# 完整构建（tsx scripts/build.ts）
pnpm run build

# 仅构建 Host
pnpm run build:lib:host
# 等价于: tsc -b tsconfig.host.json && tsdown --env.DSH_BUILD_FACE host

# 仅构建 Client
pnpm run build:lib:client
# 等价于: tsc -b tsconfig.client.json && tsdown --env.DSH_BUILD_FACE client

# 仅构建 Web UI
pnpm run build:web

# 类型检查
pnpm run typecheck

# Lint
pnpm run lint
pnpm run lint:fix
```

## 构建工具链

| 工具 | 用途 |
|:--|:--|
| `tsc` | TypeScript 类型检查 + 声明文件生成 |
| `tsdown` | ESM 打包（按 Host/Client face 分别打包） |
| `tsx` | 脚本运行器（构建/发布脚本） |
| `oxlint` | 代码检查（替代 ESLint） |

## 测试

```bash
# 运行所有测试
pnpm run test

# 覆盖率
pnpm run test:coverage
pnpm run test:coverage:partitioned    # 分区覆盖率

# E2E 测试
pnpm run test:e2e

# 快照测试
pnpm run test:snapshot
pnpm run test:snapshot:record         # 录制快照
pnpm run test:snapshot:refresh        # 刷新快照

# Web 测试
pnpm run test:web                     # 需先 build
pnpm run test:web:built               # 已构建版本
pnpm run test:web:refresh             # 刷新快照
pnpm run test:web:perf                # 性能测试
pnpm run test:web:stress              # 压力测试

# GUI 测试
pnpm run test:gui                     # 仅 client + host 包
```

## 发布流程

```bash
# 1. 版本 bump
pnpm run release:dsh           # dsh 家族
pnpm run release:vendor        # vendor 家族

# 2. 验证
pnpm run release:verify        # 发布前验证
pnpm run release:verify-packed-install  # 打包安装验证

# 3. 打包
pnpm run release:pack

# 4. 发布到 npm
pnpm run release:publish
```

## Profile 与 Bundle 机制

### Profile（配置档案）

存储在 `$DSH_HOME/profiles/<name>/`，包含：
- `package.json` — out-of-tree 插件依赖 + `dsh.profile.bundles` 列表
- `cordis.patch.yml` — 用户自定义补丁

内置模板：`web`（浏览器）和 `headless`（无服务器）

### Bundle（分发格式）

npm 包，manifest 中声明 `dsh.bundle.patch`：

| Bundle | 用途 |
|:--|:--|
| `dsh-base` | 核心层（70+ deps） |
| `dsh-web-app` | 浏览器层（100+ deps） |
| `dsh-headless` | 无服务器一次性任务 |

### 配置树查看

```bash
dsh --profile web --dump-config
```

## 环境变量

| 变量 | 必填 | 说明 |
|:--|:--|:--|
| `DEEPSEEK_API_KEY` | 是 | DeepSeek API 密钥 |
| `DEEPSEEK_BASE_URL` | 否 | 自定义 API 地址 |

凭据优先级：**进程环境变量 > `.credentials.yaml` > `.env`**
