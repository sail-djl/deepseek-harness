# Agent Preset 目录

> 5 个内置 Agent Preset，决定 Agent 的工具集、提示词和职责。
> 位置: `apps/cli/config/agent-presets/`

---

## Preset 总览

| Preset | 名称 | 描述 | 工具数 | 适用场景 |
| :-- | :-- | :-- | :-- | :-- |
| **standard** | 标准模式 | 功能完整的编码 Agent | ~23 | 日常开发、代码编写、文件操作 |
| **code** | PTC 模式 | 标准 + TypeScript 批量编排 | ~24 | 复杂多步自动化、批量操作 |
| **cordis** | 创造模式 | 标准 + 自修改运行时 | ~25 | 创建/调试 preset、插件开发 |
| **minimal** | 极简模式 | 仅 bash + 编辑器 | 3 | 快速测试、极简验证 |
| **my-agent** | 自定义模板 | 用户自定义 preset | 可变 | 个人定制 |

---

## 场景对比

### standard — 标准模式

**场景**：日常编码、文件编辑、Shell 操作、网页搜索

```
用户: "帮我修改 src/main.ts 里的函数"
Agent: tool-fs → tool-fs-search → tool-str-replace-editor
用户: "运行测试"
Agent: tool-bash → pnpm test
用户: "搜索 React 的 useContext 用法"
Agent: tool-web
```

**包含**：
- persona + agent-instructions（系统提示词）
- bash/pwsh（平台自动切换）
- fs + fs-search（文件操作）
- jobs（后台任务）
- skill + skill-filesystem（技能系统）
- goal（目标管理）
- plan-mode（计划模式）
- compaction（上下文压缩）
- subagent + workflow（子代理 + 工作流）
- ask-user + todo + web

### code — PTC 模式

**场景**：复杂多步操作，用 TypeScript 程序组合多个工具调用

```
用户: "批量重命名 src/ 下所有 .js 文件为 .ts"
Agent: tool-presentation (mode: code)
  → 模型写一个 TypeScript 程令
  → run_code 一次性执行
  → 5 次工具调用 → 1 次 run_code
```

**额外能力**：
- `tool-presentation` (mode: code) — 模型写 TypeScript 程序，一次执行多步操作
- 适合：批量文件操作、数据转换、多步骤自动化

### cordis — 创造模式

**场景**：创建/调试 Agent Preset、插件开发

```
用户: "创建一个新的 preset"
Agent: tool-cordis → 读取运行时、挂载/卸载插件
用户: "修改 agent.cordis.yml"
Agent: editing-cordis-compositions skill → 教 Agent 写 preset
```

**额外能力**：
- `tool-cordis` — 读写运行时、挂载/卸载插件
- `editing-cordis-compositions` skill — 教 Agent 如何编辑 preset

**信任警告**：tool-cordis 执行模型编写的 JavaScript，等同于 shell 权限。

### minimal — 极简模式

**场景**：快速测试、极简验证、最小化环境

```
用户: "运行 ls -la"
Agent: persistent-bash → ls -la
用户: "修改文件第 10 行"
Agent: str-replace-editor → 替换内容
```

**仅包含**：
- persona（固定提示词，complete: true）
- persistent bash/pwsh（持久终端）
- str_replace_editor（编辑器）

**无**：fs-search、web、skill、goal、plan、compaction、subagent、workflow

### my-agent — 自定义模板

**场景**：用户基于 standard 复制并修改

```
目录为空 → 首次使用时需要复制 standard 并编辑
```

## 选择指南

```
需要什么能力？
  │
  ├─ 只需 bash + 编辑器 → minimal
  ├─ 完整编码能力 → standard
  ├─ 批量多步操作 → code
  ├─ 创建/调试 preset → cordis
  └─ 自定义 → 复制 standard 到 my-agent/
```

## 与 Profile 的关系

```
Profile (package.json)
  bundles: [dsh-base, dsh-web-app]
    ↓
agent-presets 插件 (Layer 2 注入)
    ↓
扫描 agent-presets 目录
    ↓
用户选择 preset → 加载 agent.cordis.yml
    ↓
插件注册到 Agent
```

Profile 决定"有哪些基础能力"，Preset 决定"这个 Agent 用哪些工具"。
