# CLI 源码层 (apps/cli/src/)

> 6 个 TypeScript 源文件，构成 `@deepseek-ai/dsh` CLI 的完整入口。

## 文件职责

| 文件 | 职责 | 行数 |
| :-- | :-- | :-- |
| `bin.ts` | CLI 入口：`#!/usr/bin/env node`，按 mode 动态 import 分发 | ~53 |
| `args.ts` | commander 参数解析：`--profile` / `--patch` / `--dump-config` / `web` / `plugin` | ~191 |
| `profile-boot.ts` | Profile 启动核心：composeProfile + runProfile + HMR 监听 | ~300 |
| `plugin.ts` | 插件管理：pnpm 转发 + reconcile bundles | ~158 |
| `dump-config.ts` | 配置导出：组合 patch 层后打印（不启动） | ~53 |
| `process-shutdown.ts` | 进程关闭处理：信号 + 超时 + 优雅退出 | ~60 |

## 调用链路

```
bin.ts (入口)
  ├─ args.ts           parseDshArgs() → DshInvocation
  ├─ profile-boot.ts   runProfile()   → boot Cordis 容器
  ├─ plugin.ts         runPlugin()    → spawnSync pnpm
  └─ dump-config.ts    runDumpConfig() → renderConfigDump()
```

## 注意事项

- `bin.ts` 每次启动**重写**空根 `cordis.yml`，防止 Loader write-back 导致 bundles 重复
- `profile-boot.ts` 的 `composeLive` 和 `boot` 都用 `structuredClone` 克隆 patch，防止 insert 引用污染
- `plugin.ts` 的 `anchorPathSpec` 将相对路径锚定到调用 cwd，防止 pnpm 在 profile 目录自解析
