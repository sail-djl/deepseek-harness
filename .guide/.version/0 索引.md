# 版本变更跟踪（索引）

> 本目录跟踪 dsh（DeepSeek Harness）的**版本变更**，每个版本一个独立文档。
> 用途：定位「某个版本引入了哪些需要迁移的变更」，以及本 guide 仓库同步到了哪个版本。

---

## 一、维护约定（硬规则）

| 编号 | 约定 |
|:--|:--|
| R1 | **每次版本升级都必须新增一个 `<版本号>.md`**（上游 `release(dsh): <版本号>` 提交 + 打 `dsh-v<版本号>` tag 即视为一次升级） |
| R2 | 文件名和正文**必须是完整具体版本号**，含预发布后缀（`alpha` / `beta` / `rc`），不加 `v` 前缀 |
| R3 | **只追加不修改**：已写好的版本记录不改写；发现错误时在文末追加「更正」小节 |
| R4 | 记录必须**可溯源**：版本提交 hash、上游 tag、Release 链接、上游合并 PR、核对命令缺一不可 |
| R5 | 本章节「版本总览」表在新增版本时**同步追加一行** |
| R6 | **变更清单以上游 Release 发布说明为准**（GitHub Release，tag 命名 `dsh-v<版本号>`）；抓取不到时才回退到提交区间统计，并注明回退原因 |

**覆盖范围**：起始只回填**最近三个版本**（`0.2.0-rc.2` 起），不回填更早历史；此后每次升级持续追加、累积保留（不滚动删除）。

> 如需调整覆盖范围（例如改成「永远只保留最近三个」的滚动窗口），改本节即可，不动各版本文档。

## 三、单版本文档标准章节

新增版本时按此结构写，便于对比各版本：

| 章节 | 内容 |
|:--|:--|
| 一、基本信息 | 版本号 / 版本类型 / 发布日期 / 上游 tag / Release 链接 / 版本提交 / 上游合并 PR / 上一版本 |
| 二、变更统计 | 区间提交总数 + 按提交类型分布（佐证用） |
| 三、上游发布说明 | **R6 主来源**：Release 说明中文部分原文照录（新增功能 / 问题修复 / 体验优化 / 其他变更） |
| 四、升级说明条目 | 摘录 `docs/upgrade-guide/v<版本号>/` 下每个子目录的 `description`（含迁移步骤）；上游未提供时写明并给出同类条目参照 |
| 五、持久化 / 会话格式变更 | `docs/persistence-changes/` 中落在本区间的新增条目 |
| 六、本仓库同步记录 | 本 guide 仓库何时、经由哪个合并提交引入该版本 |
| 七、依据与核对命令 | 复核用的 Release API URL + git 命令 |

## 四、新增版本的操作流程

1. 找到版本提交：`git log --format="%h|%ad|%s" --date=short --grep="^release(dsh):" | head`
2. 确认 tag 已抓到：`git fetch --tags upstream`，再 `git tag -l "dsh-v<版本号>"`
3. **取上游发布说明（R6 主来源）**：
   `curl -s https://api.github.com/repos/deepseek-ai/deepseek-harness/releases/tags/dsh-v<版本号>`
   取 `body` 字段里的**中文部分**（`<h3 id="cn-...">` 到 `<h3 id="en-...">` 之间）原文照录
4. 找到上游合并 PR：`git log --merges --format="%h|%ad|%s" --date=short --grep="<版本号>"`
5. 统计区间：`git rev-list --count <上一版本提交>..<本版本提交>`
6. 收集升级说明：`ls docs/upgrade-guide/v<版本号>/`，逐个读 `guide.zh.md` 的 `description`
7. 核对持久化变更：`ls docs/persistence-changes/ | grep "<YYYY-MM-DD>"`
8. 按「三、单版本文档标准章节」写 `<版本号>.md`，并在「二、版本总览」追加一行

## 五、依据与核对命令

```bash
# 最近 release 提交序列
git log --format="%h|%ad|%s" --date=short --grep="^release(dsh):"

# 上游 tag 命名与本地 tag 列表
git fetch --tags upstream && git tag -l "dsh-v*" --sort=-creatordate | head

# 某版本的上游发布说明（R6 主来源）
curl -s https://api.github.com/repos/deepseek-ai/deepseek-harness/releases/tags/dsh-v<版本号>

# 某版本的全部升级说明条目（description 一行摘要）
grep -rn "^description:" docs/upgrade-guide/v<版本号>/

# 某版本的持久化 / 会话格式变更
ls docs/persistence-changes/ | grep "<YYYY-MM-DD>"

# 区间提交类型分布
git log --format="%s" <上一版本提交>..<本版本提交> \
  | sed -E 's/^([a-zA-Z]+).*/\1/' | sort | uniq -c | sort -rn
```
