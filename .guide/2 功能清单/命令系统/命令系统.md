# 命令系统（Slash Commands）

DSH 的 `/` 斜杠命令系统，用户在输入框输入 `/` 触发命令菜单，选择后直接执行（不经过模型）。

## 一、架构概览

双层架构：

| 层 | 注册方式 | 说明 |
|:--|:--|:--|
| **Host 端**（后端） | `ctx.commands.register()` | Cordis 服务，命令在服务端执行，结果通过 RPC 返回 |
| **Client 端**（前端） | `commandUi.register()` | 浏览器端执行，如模型选择弹窗 |

核心注册表：[packages/interaction/commands/src/index.ts](../../packages/interaction/commands/src/index.ts)（`CommandRuntime` 类）

## 三、各命令详解

### 3.1 `/compact` — 压缩历史

- 无参数
- 调用 `ctx.compaction.compactNow()` 手动触发对话压缩

### 3.2 `/export` — 导出会话

- 无参数，Web-only
- 返回 success，实际下载由 Host 端 HTTP route 处理

### 3.3 `/feedback` — 记录反馈

- 输入：`<text>`（自由文本）
- `recordInput: false`（输入由领域事件 `feedback/record` 持有，不重复记录到 `command/run`）

### 3.4 `/goal` — 任务目标

- 输入：`[<objective>|clear|edit <objective>|pause|resume]`
- 支持图片附件（`images: true`）
- 子命令：create / edit / pause / resume / clear / show

### 3.5 `/permission` — 权限切换

- 输入：`<preset>`
- 空参数显示当前预设，有参数切换到指定预设

### 3.6 `/plan` — 计划模式

- 输入：`[off|message]`
- `plan off` 关闭；其他内容或空参数开启并可附带消息
- 同时注册 model-facing 工具 `exit_plan_mode`

### 3.7 `/model` — 模型选择

- **唯一 Client 端命令**，通过 `commandUi.register()` 注册
- 类型：`popupSelect`，弹出模型选择列表
- 条件：仅在非子 agent 会话中可用

## 四、注册 API

```ts
// Host 端：通过 Cordis 服务注册
ctx.commands.register({
  name: 'mycommand',           // 小写，不含 /
  description: '命令描述',      // 显示在菜单中
  input: { hint: '<arg>' },    // 可选：输入提示
  recordInput: true,           // 可选：是否记录原始输入（默认 true）
  handler(invocation) {
    // invocation.agent     — 目标 agent
    // invocation.rawInput  — 命令名后的原始文本
    // invocation.attachments — 图片附件（需声明 images: true）
    // invocation.signal    — 取消信号
    return { kind: 'success', text: '结果' }
    // 或 { kind: 'error', text: '错误信息' }
  }
})
```

### 核心接口

| 接口 | 说明 |
|:--|:--|
| `CommandDefinition` | 注册定义（name + description + input + handler） |
| `CommandInvocation` | 传给 handler 的调用上下文 |
| `CommandResult` | 执行结果（success/error） |
| `CommandDescriptor` | 不含 handler 的只读描述符（用于 UI 发现） |
| `ParsedCommand` | 解析后的命令（name + rawInput） |

## 五、UI 运行时

命令菜单由前端 [packages/client/ui-commands/src/client/service.ts](../../packages/client/ui-commands/src/client/service.ts) 的 `CommandUiRuntime` 组装：

1. `/` 触发 → 调用 `candidates()` 合并 Host 命令目录 + Client 贡献
2. 支持模糊搜索
3. 回车提交 → `dispatch()` 处理：贡献命令打开弹窗，裸命令直接执行
4. `command/run` → handler → `command/done` 生命周期事件记录到会话日志

---

## 六、如何添加自定义命令

每个命令是独立的 Cordis 插件，遵循标准模式：

1. 创建插件包（参考 `command-compact` 等现有包）
2. 在 `apply()` 中调用 `ctx.commands.register()`
3. 返回 disposer 用于注销
4. 插件通过 Cordis 组合自动生效

详见 [插件命令注册说明](../../.agents/notes/implemented/feature/2026-07-19-plugin-command-registration.zh.md)
