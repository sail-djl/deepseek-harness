# 配置说明

## apps/cli (@deepseek-ai/dsh)

### 入口分发

`bin.ts` 按 mode 动态 import：

| mode | 说明 | 入口 |
| :-- | :-- | :-- |
| `profile` | 启动指定 profile | `profile-boot.ts` |
| `plugin` | 插件管理 | `plugin.ts` |
| `web` | 启动 Web UI | `profile-boot.ts` (web profile) |
| `dump-config` | 导出配置树 | `dump-config.ts` |

### 内置 Agent Preset

位于 `config/agent-presets/`：

| Preset | 说明 | 工具数 |
| :-- | :-- | :-- |
| `standard` | 完整编码 Agent | ~15 |
| `cordis` | standard + 自修改运行时 | ~16 |
| `code` | standard + TypeScript 批量编排 | ~16 |
| `minimal` | 仅 bash + 编辑器 | 3 |
| `my-agent` | 用户自定义 preset | 可变 |

### Profile 加载链

```
.dsh/profiles/<name>/package.json
  → dsh.profile.bundles 数组（按顺序加载）
    → 每个 bundle 的 cordis.patch.yml（insert/disable/override）
      → profile cordis.patch.yml（Profile 级覆盖）
        → 用户级 cordis.patch.yml
          → --patch 外部文件
```

## apps/web (@deepseek-ai/dsh-web-frontend)

### Vite 配置

- 入口: `src/main.ts`
- 构建产物: `dist/`（被 cli 的 `dsh web` 静态托管）
- 框架: React 18 + TypeScript 6

### 前端模块

| 模块 | 包名 | 说明 |
| :-- | :-- | :-- |
| shell | `@deepseek-ai/dsh-client-web` | 应用外壳 |
| modules | `@deepseek-ai/dsh-client-modules` | 模块注册 |
| primitives | `@deepseek-ai/dsh-client-ui-primitives` | 基础 UI 组件 |
| slots | `@deepseek-ai/dsh-client-ui-slots` | 插槽系统 |

## 环境变量

| 变量 | 必填 | 说明 |
| :-- | :-- | :-- |
| `DEEPSEEK_API_KEY` | 是 | DeepSeek API 密钥 |
| `DEEPSEEK_BASE_URL` | 否 | 自定义 API 地址 |
| `DSH_HOME` | 否 | DSH 配置目录 (默认 `~/.dsh`) |
| `DSH_CWD` | 否 | 工作目录 (默认 `process.cwd()`) |

## 配置文件位置

| 文件 | 路径 | 说明 |
| :-- | :-- | :-- |
| 项目级 profile | `.dsh/profiles/<name>/` | 团队共享配置 |
| 用户级 profile | `~/.dsh/profiles/<name>/` | 个人本地覆盖 |
| 用户级 settings | `~/.dsh/settings.yaml` | 全局设置 |
| 用户级 credentials | `~/.dsh/.credentials.yaml` | 凭据 |
