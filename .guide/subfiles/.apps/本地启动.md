# 本地启动

## 前置依赖

| 依赖 | 版本要求 | 说明 |
| :-- | :-- | :-- |
| Node.js | ^22.19.0 或 >=24.0.0 | 运行时环境 |
| pnpm | 11.7.0+ | 包管理器 |
| Git | 2.26+ | 版本控制 |

## 从源码启动

```bash
# 1. 在 monorepo 根目录安装依赖
cd DeepSeekHarness
pnpm install

# 2. 构建所有包
pnpm run build

# 3. 启动 Web UI（默认端口 3080）
pnpm dsh web

# 4. 或指定 profile 启动
pnpm dsh --profile web --dump-config   # 查看配置树
pnpm dsh web --no-open                 # 启动但不打开浏览器
```

## 仅开发 Web 前端（带 HMR）

```bash
# 在 monorepo 根目录
pnpm run dev:web
# 或在 apps/web 目录
cd apps/web && pnpm dev
```

## CLI 常用命令

| 命令 | 说明 |
| :-- | :-- |
| `pnpm dsh web` | 启动 Web UI (默认 http://127.0.0.1:3080) |
| `pnpm dsh web --no-open` | 启动但不自动打开浏览器 |
| `pnpm dsh --dump-config` | 查看完整配置树 |
| `pnpm dsh --profile <name>` | 指定 profile 启动 |
| `pnpm dsh plugin list` | 列出已安装插件 |
| `pnpm dsh --version` | 查看版本 |

## 构建命令

```bash
# 完整构建
pnpm run build

# 仅构建 Host（服务端）
pnpm run build:lib:host

# 仅构建 Client（客户端）
pnpm run build:lib:client

# 仅构建 Web 前端
pnpm run build:web

# 类型检查
pnpm run typecheck

# 测试
pnpm run test
```

## Agent Preset 开发

```bash
# 查看当前可用 preset
pnpm dsh --dump-config | Select-String "preset"

# 使用创造模式调试 preset
pnpm dsh --profile web --mode cordis

# 查看某个 profile 的配置
pnpm dsh --profile product-agent --dump-config
```

## 排查问题

- 如果 `pnpm --version` 无法解析，运行 `corepack enable`
- 安装后首次运行 `pnpm run typecheck` 验证环境
- Lefthook hooks 在 `pnpm install` 时自动配置
- 如缺失，手动运行 `node scripts/install-lefthook.mjs`
