# 本地启动

## 前置依赖

| 依赖 | 版本要求 | 说明 |
|:--|:--|:--|
| Node.js | ^22.19.0 或 >=24.0.0 | 运行时环境 |
| pnpm | 11.7.0+ | 包管理器 |
| Git | 2.26+ | 版本控制 |

## 从源码安装

```bash
# 1. 克隆仓库
git clone https://github.com/deepseek-ai/deepseek-harness.git
cd deepseek-harness

# 2. 安装依赖
pnpm install

# 3. 构建项目
pnpm run build

# 4. 启动 Web UI
pnpm dsh web
```

## 从 npm 快速安装

```bash
npx @deepseek-ai/dsh web
```

## 常用命令

| 命令 | 说明 |
|:--|:--|
| `pnpm install` | 安装依赖 |
| `pnpm run build` | 完整构建 |
| `pnpm dsh web` | 启动 Web UI (默认 http://127.0.0.1:3080) |
| `pnpm dsh web --no-open` | 启动但不自动打开浏览器 |
| `pnpm run typecheck` | 类型检查 |
| `pnpm run test` | 运行测试 |
| `pnpm run lint` | 代码检查 |
| `pnpm run build:web` | 仅构建 Web 前端 |
| `pnpm dsh --dump-config` | 查看完整配置树 |

## 环境变量

在项目根目录创建 `.env` 文件：

```
DEEPSEEK_API_KEY=sk-...
DEEPSEEK_BASE_URL=https://...   # 可选，自定义 API 地址
```

## 开发模式

```bash
# 仅开发 Web 前端（带 HMR）
pnpm run dev:web
```

## TypeScript 架构说明

项目使用双聚合架构：

- **Host 聚合** (`tsconfig.host.json`)：服务端包
- **Client 聚合** (`tsconfig.client.json`)：客户端包

构建顺序：
```bash
tsc -b tsconfig.host.json        # 编译 Host
tsdown --env.DSH_BUILD_FACE host  # 打包 Host
tsc -b tsconfig.client.json      # 编译 Client
tsdown --env.DSH_BUILD_FACE client # 打包 Client
pnpm run build:web               # 构建 Web UI
```

## 排查问题

- 如果 `pnpm --version` 无法解析，运行 `corepack enable`
- 安装后首次运行 `pnpm run typecheck` 验证环境
- Lefthook hooks 在 `pnpm install` 时自动配置，如缺失手动运行 `node scripts/install-lefthook.mjs`
