# 项目概览与快速开始

> 项目：DeepSeek Harness（dsh）· 版本：0.2.1-alpha.5（package.json `@deepseek-ai/dsh-root`）

## 1. 项目背景

DeepSeek Harness（简称 dsh）是 DeepSeek AI 开源的 agent harness（智能体运行框架），采用「一切皆插件」架构，底层由 Cordis 框架驱动：插件向共享上下文贡献服务、类型化事件与可回滚的 effect，模型适配器、工具注册表、会话日志乃至 agent loop 本身都是可从配置替换的插件。项目处于 developer preview 阶段，公开 API 未稳定，存在兼容性破坏性变更。

- 上游仓库：https://github.com/deepseek-ai/deepseek-harness
- 官方文档：https://deepseek-harness.github.io/deepseek-harness/
- 许可证：MIT

## 2. 核心功能

- Agent 会话：追加式 SessionEvent 日志与内存存储（`packages/core/session`）
- Agent loop：默认驱动，step/turn 模型（`packages/core/agent-loop`）
- 工具系统：作用域化工具注册表与受保护执行管线（`packages/core/tools`）
- LLM 适配：消息/流词汇表与适配器 seam（`packages/llm`）
- 执行能力：shell 命令、子进程、SSH、持久终端、PTC 运行时
- 沙箱与安全：进程隔离沙箱（`packages/sandbox`）、审批策略
- 浏览器与电脑使用：browser-use / computer-use、web 搜索抓取
- MCP：外部工具接入（`packages/mcp`）
- 会话与存储：持久会话、会话查询导出、附件、spill、通用 storage
- 编排能力：子代理、后台任务、workflow、todo、plan、goal、schedule
- 双端 GUI：Web 应用（`apps/web`）与 Electron 桌面应用（`apps/desktop`）
- SDK：TypeScript JSON-RPC SDK 与 Python SDK（`python/`）
- 插件生态：profile/bundle 组合、插件管理器、插件市场生成器

## 3. 技术架构

- 底层框架：Cordis（`vendor/` 内置源码副本），一切皆插件，无特权核心
- 组合模型：profile（命名组合）→ 有序 bundle 层 → `cordis.patch.yml` → home patch → `--patch` overlay
- 出厂 profile：web / headless / sdk / sdk-minimal / acp（`dsh --profile <name>` 启动）
- 语言与模块：TypeScript 全量 ESM（`"type": "module"`），strict 模式
- 桌面端：Electron（`apps/desktop`），内置 dsh 生产运行时 + Desktop Host
- Web 前端：Vite 构建 `@deepseek-ai/dsh-client-web`（`apps/web`），由 `dsh web` 提供服务
- 原生层：`@deepseek-ai/node-addon-system`（`native/`）
- Python：SDK/运行时（`python/`）
- 详细架构：见 `../docs/architecture.md`

## 4. 项目结构说明

| 目录 | 说明 |
|:--|:--|
| `vendor/` | Cordis 源码副本（含 upstream SHA 清单） |
| `packages/<组>/<包>/` | `@deepseek-ai/dsh-<name>` 工作区包，按组组织 |
| `apps/cli` | dsh CLI 与 web 服务入口 |
| `apps/desktop`、`apps/desktop-host` | Electron 桌面壳与私有 Desktop Host |
| `apps/web` | Web 前端（Vite） |
| `python/` | Python SDK/运行时 |
| `native/` | node-addon-system 原生扩展源码 |
| `docs/` | 架构/子系统/开发文档 |
| `scripts/` | 构建、门禁与生成器 |
| `benchmarks/`、`snapshots/` | 性能门禁与录制会话快照 |
| `website/` | VitePress 文档站 |

主要包组（`packages/` 下）：core、api、typert、llm、shell、subprocess、ssh、terminal、ptc-runtime、sandbox、fs、lsp、skill、web、computer-use、browser-use、compaction、context、subagent、jobs、bundle、workflow、todo、plan、goal、schedule、preset、guard、extensions、session、session-query、attachment、spill、storage、workspace、feedback、identity、settings、credentials、acp、interaction、boot、sdk、host、client、mcp、experimental、test-support、util。

## 5. 开发环境要求

| 依赖 | 版本要求 | 用途 |
|:--|:--|:--|
| Node.js | ^22.19.0 或 >=24.0.0 | 运行与构建 |
| pnpm | 11.28.5（packageManager 指定） | workspace 安装与脚本 |
| Python | 按 `python/` 需要 | Python SDK/运行时 |
| 操作系统 | Windows / macOS / Linux | 桌面端按平台打包 |

快速验证（详见 `本地启动.md`）：

```sh
pnpm install
pnpm run build
pnpm dsh web
```
