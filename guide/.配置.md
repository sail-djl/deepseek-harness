# 配置文件说明

> dsh 根目录关键配置文件速查（配置参数以各文件与官方 docs 为准，本文件只做定位导航）。

| 文件 | 作用 | 关键点 |
|:--|:--|:--|
| `pnpm-workspace.yaml` | workspace 成员与依赖策略 | `vendor/*`、`packages/*/*`、`native/system`、`apps/*`、`website` |
| `package.json` | 根脚本入口 | build/test/typecheck/lint/check:* 等门禁与打包脚本 |
| `tsconfig.base.json` / `tsconfig.host.json` / `tsconfig.client.json` | TypeScript 工程面（host/client 双面） | strict；源面经 paths 解析到 src，产物面走 lib/ |
| `tsdown.config.ts` | tsdown 打包配置 | runtime bundle |
| `vitest.config.ts` 及 `vitest.*.config.ts` | 测试矩阵 | unit/e2e/snapshot/web/bench/perf/expected |
| `.oxlintrc.json`、`.oxlintrc.staged.json` | oxlint 规则 | staged 配置供 pre-commit |
| `.jscpd.json` | 跨文件重复检测 | duplication 脚本使用 |
| `lefthook.yml` | git hooks | pre-commit 门禁 |
| `.gitlab-ci.yml` | CI 流水线 | check:ci:* 系列 |
| `pytest.ini` | Python 侧测试配置 | `python/` |
| `Makefile` | 常用命令别名 | `make web / dev-web / desktop / build`，`make help` 列全表 |

## 运行时插件配置（用户侧，不在仓库内固定）

- `cordis.yml` / `cordis.patch.yml`：插件树配置；`!!js`（非 `!js`）可在插件 `config` 与 entry `disabled` 下使用
- profile 与 bundle 通过 `package.json` 的 `dsh.profile` / `dsh.bundle` 字段声明
- 查看本机实际启动的插件树：`dsh --profile web --dump-config`
