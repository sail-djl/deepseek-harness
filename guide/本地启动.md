# 本地启动指南

> dsh 是多步骤构建链的 pnpm monorepo（含原生模块与 Electron 打包），不满足「`npm install && npm run dev` 即可启动」的简单场景，故有本文件。

## 前置依赖

| 依赖 | 版本要求 | 用途 |
|:--|:--|:--|
| Node.js | ^22.19.0 或 >=24.0.0 | 运行时/构建 |
| pnpm | 11.28.5 | workspace 管理 |
| Python | 按 `python/` 需要 | Python SDK 运行时 |
| Git | 任意近期版本 | 源码检出 |

## 安装依赖

```sh
pnpm install
```

## 开发模式

Web（构建产物 + 源码编辑时重建客户端 bundle，单终端）：

```sh
pnpm run dev:web
```

桌面端：

```sh
pnpm run dev:desktop
```

跳过构建直接启动（需先有构建产物）：

```sh
pnpm run start:web       # root start:web/dev:web 属受控入口分类，见 verify-application-entrypoints
pnpm run start:desktop
```

从源码运行一个任务（headless，需要 `DEEPSEEK_API_KEY`）：

```sh
pnpm dsh --profile headless "task"
```

## 构建产物

```sh
pnpm run build             # build:artifacts + build:check 并发
pnpm run build:artifacts   # tsc 产出 lib/types、tsdown 打包 runtime 与 Web
pnpm run build:web         # 仅 Web 前端
pnpm run build:desktop     # 仅桌面端
```

Windows 安装包：

```sh
pnpm run package:desktop:win:x64
```

## 常用检查

```sh
pnpm run typecheck
pnpm run lint
pnpm run test              # 单元测试
pnpm run check:all         # 全量门禁
```

## 环境变量说明

| 变量 | 用途 |
|:--|:--|
| `DEEPSEEK_API_KEY` | 真实 API 测试/demos 必需；缺失时 e2e 自动跳过 |
| `DEEPSEEK_BASE_URL` | 可选，覆盖 API 地址 |
| 根目录 `.env` | 本地密钥存放处，禁止提交凭据 |

启动后 Web UI 默认地址：`http://127.0.0.1:3080`。
