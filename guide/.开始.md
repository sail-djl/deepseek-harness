# 项目概览与快速开始

> DeepSeek Harness（dsh）· 版本：0.2.1-alpha.5（package.json `@deepseek-ai/dsh-root`）· 许可证：MIT
> 上游仓库：https://github.com/deepseek-ai/deepseek-harness · 官方文档：https://deepseek-harness.github.io/deepseek-harness/
> DeepSeek AI 开源的 agent harness（智能体运行框架），「一切皆插件」（Cordis 微内核）；developer preview 阶段，公开 API 未稳定。

## 核心功能

- Agent 会话 / Agent loop（step/turn 模型）、作用域化工具系统与受保护执行管线
- LLM 适配器 seam；执行能力：shell、子进程、SSH、持久终端、PTC
- 沙箱与审批策略、浏览器/电脑使用、MCP 外部工具接入
- 编排：子代理、后台任务、workflow、todo、plan、goal、schedule
- 双端 GUI：Web（`apps/web`）与 Electron 桌面（`apps/desktop`）；TypeScript / Python SDK
- 插件生态：profile/bundle 组合、插件管理器、插件市场

## 快速验证

```sh
pnpm install && pnpm run build && pnpm dsh web   # Web UI: http://127.0.0.1:3080
```

> 分工原则（单一维护点）：环境要求/启动排障 → `本地启动.md`；整体架构、项目结构与包组 → `架构/1 整体架构.md`；本文只做概览与指路，不复制别处维护的细节。
