# 前端架构

> 覆盖 Web 前端（`apps/web`）、桌面壳（`apps/desktop`）与 GUI 客户端库（`packages/client`、`packages/host`）。整体架构见 `../1 开始.md`；本文件只描述前端/客户端侧。

## 组成

| 部分 | 位置 | 职责 |
|:--|:--|:--|
| Web 前端 | `apps/web`（`@deepseek-ai/dsh-web-frontend`） | Vite 构建 `@deepseek-ai/dsh-client-web` shell 库；dist/ 由 `apps/cli` 的 `dsh web` 提供服务 |
| GUI 客户端库 | `packages/client` | 客户端插件与卡片呈现；Web cards 由原始事件与持久化结果元数据派生 |
| GUI 宿主 | `packages/host` | Electron/Web 宿主呈现器，保持纯函数 |
| 桌面壳 | `apps/desktop`（`@deepseek-ai/dsh-desktop`） | Electron 外壳：内置 dsh 生产运行时（签名资源）与外部插件管理 |
| Desktop Host | `apps/desktop-host` | Electron Node 模式运行的私有 Host：调用共享 CLI profile runner 与完整 Web 应用 |

## 运行时数据流（桌面端）

1. Electron 启动私有 Desktop Host（Electron Node 模式）。
2. Host 调用共享 CLI profile runner 与完整 Web 应用。
3. 窗口立即加载打包的 Web 资源，等待 boot 注入后再在同一文档内激活客户端插件。
4. Web 负责 RPC 与流；桌面载体把本地页面连接到已认证的 Host。
5. Node IPC 承载 boot 注入、就绪、致命错误与关闭。
6. 端口默认由 OS 分配，可用 profile 配置覆盖。

## 约定

- 客户端 UI 文案归 locale 所有：经类型化字典与 `t`（或本地化原语 props）输出，`verify-client-ui-i18n` 拒绝硬编码文案。
- 工具的 UI 呈现需提前设计：宿主呈现器保持纯函数，Web 卡片从原始事件与持久化结果元数据派生。
