# Apps 架构

## 整体架构

```
用户终端
  │
  ├── pnpm dsh web ──→ apps/cli (bin.ts)
  │                       ├── 解析命令行参数
  │                       ├── 加载 profile
  │                       ├── 启动 Cordis 容器
  │                       ├── 加载 plugin tree
  │                       └── 启动 Web Server
  │                            ├── 静态托管 apps/web/dist/
  │                            ├── API Proxy → dsh 内部 API
  │                            └── WebSocket → Session 实时通信
  │
  └── 浏览器 ──→ apps/web (main.ts)
                    └── AppWebEntry → React SPA
                         ├── 侧边栏 (workspace/session 列表)
                         ├── 对话区 (消息流)
                         ├── 工具面板 (工具调用展示)
                         └── 设置页 (model/plugin 配置)
```

## CLI 分发流程

```typescript
// apps/cli/src/bin.ts
switch (invocation.mode) {
  case 'profile':  → runProfile()        // 启动指定 profile
  case 'plugin':   → plugin management   // 插件管理
  case 'web':      → runProfile(web)     // 启动 Web UI
  case 'dump-config': → dumpConfig()     // 导出配置
}
```

## Profile 加载链

```
1. parseDshArgs()          解析 --profile / --patch 参数
2. loadLayeredEnv()        加载环境变量 (.env)
3. runProfile()            启动 profile
4. cordis loader           加载 package.json bundles
5. bundle patch layers     按顺序应用 cordis.patch.yml
6. user patch layers       用户级覆盖
7. --patch external files  外部 patch 文件
8. web server start        启动 HTTP + WebSocket
```

## 前端模块架构

```
apps/web/main.ts
  └── AppWebEntry (dsh-client-web)
       ├── Connection      WebSocket 连接管理
       ├── SessionRuntime  Session 状态管理
       ├── WorkspaceRuntime 工作区管理
       ├── UI Renderer     React 组件渲染
       └── Slots           插槽系统 (plugin UI 注入)
```

## 内置 Preset 架构

```
config/agent-presets/
├── standard/agent.cordis.yml    ← 标准模式 (基础)
├── cordis/agent.cordis.yml      ← standard + tool-cordis + skill
├── code/agent.cordis.yml        ← standard + tool-presentation
├── minimal/agent.cordis.yml     ← 仅 bash + editor
└── my-agent/agent.cordis.yml    ← 用户自定义
```

每个 preset 通过 `agent.cordis.yml` 声明工具集，注册到 DSH 的 agent-preset 注册表。
